Detection Settings Reference

Note
Changes on this page only apply to new analyses. If a video has already been analyzed, clear the detection logs or re-run the analysis to use the latest settings.
Parameter Function If increased If decreased
Global Confidence Base confidence threshold from the YOLO model before further processing. Fewer false positives, but small motorcycles may be missed more often. Higher recall, but noise and false detections may increase.
Motorcycle Min Confidence Minimum threshold specifically for motorcycle detections. More selective; distant/small motorcycles may be dropped. Small motorcycles easier to capture; risk of non-motorcycle detections rises.
Car / Bus / Truck Min Confidence Per-class minimum threshold after global confidence. Cleaner results for the class; ambiguous vehicles may be discarded. Class appears more easily; misclassification rate may increase.
IOU Threshold Controls how aggressively NMS removes overlapping boxes. More overlapping boxes retained; useful for close-together motorcycles. Overlapping boxes removed faster; motorcycles near other vehicles may be lost.
Frame Stride Interval between analyzed frames. 1 = densest sampling. Faster processing, but fast-moving motorcycles easier to miss. Better motion accuracy. For motorcycles, keep at 1.
Target Analysis FPS Target number of frames per second processed for analysis. Fast motorcycles detected more stably; processing load increases. Lighter processing; small/fast objects more likely to be skipped.
Working Max Width Maximum frame width entering the inference pipeline. More detail; small motorcycles recognized better; slower processing. Faster analysis; detail for small motorcycles may decrease.
Preview FPS Frequency of preview image updates during analysis. Preview refreshes more frequently; slightly higher I/O usage. Lighter preview; minimal effect on detection accuracy.
Preview Max Width Maximum width of preview images sent to the UI. More detailed preview; larger file size. Lighter preview; reduced visual detail.
Preview JPEG Quality JPEG compression quality for preview images. Clearer preview; larger file size. Smaller, lighter preview; image quality decreases.
Recommendations when many motorcycles are missed
Keep Frame Stride at 1, raise Target Analysis FPS to 20 or 25, try Working Max Width 1920, and raise IOU Threshold to around 0.55 if many motorcycles are close together.
Model limitations
If raw YOLO output does not produce the motorcycle class, settings changes alone will not be sufficient. The strongest solution is fine-tuning the model with local CCTV data containing Indonesian motorcycles, high camera angles, small objects, and real road conditions.
